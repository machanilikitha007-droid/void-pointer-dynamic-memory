# Void Pointer with Dynamic Memory

## Author
M.Likitha

## Description
This program demonstrates using a void pointer with
dynamically allocated memory.

The memory is allocated using malloc(), and the void
pointer is type-cast to an int pointer before storing
and reading the value.

## Concepts Used
- Void pointer
- malloc()
- Dynamic memory allocation
- Type casting
- Dereferencing
- free()

## How to Run

gcc void_pointer_dynamic_memory.c -o void_pointer_dynamic_memory

./void_pointer_dynamic_memory

## Sample Output

Value stored using void pointer: 150
